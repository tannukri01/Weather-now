A React + Vite + Tailwind CSS weather application that displays real-time weather data using the Open-Meteo API and changes background videos dynamically based on the current weather condition.

🚀 Features

🌍 Get real-time weather by city name

🌡️ Displays temperature, humidity, wind speed, and coordinates (latitude & longitude)

🎥 Dynamic background videos based on weather condition (Sunny, Rainy, Cloudy, etc.)

💨 Automatically fetches local weather using your location

⚡ Built with Vite for fast development and Tailwind CSS for responsive design

🧠 Tech Stack

Frontend: React (Vite)

Styling: Tailwind CSS

API: Open-Meteo Weather API
