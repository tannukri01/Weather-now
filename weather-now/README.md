# 🌦️ Weather Now

A beautiful **real-time weather app** built with **React + Vite** that dynamically changes background videos (sunny, cloudy, rainy, snowy) based on the live weather conditions of any city using the **Open-Meteo API**.

---

## 🚀 Features

- 🌍 Search weather by city name  
- 🎥 Dynamic background video changes with weather  
- 🌡️ Real-time temperature, windspeed, and location info  
- ⚡ Fast and responsive (built with Vite + Tailwind CSS)  
- 💾 No API key required (uses Open-Meteo free API)
